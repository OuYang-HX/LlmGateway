## 一、整体概览

### 1.1 页面风格

- **主题**：深色系（Dark Mode），背景色 `#0f172a`（深蓝黑），前景色 `#e2e8f0`（浅灰白）
- **布局**：单页应用（SPA），顶部 Tab 导航 + 内容区域，最大宽度 1400px 居中
- **字体**：系统字体栈（-apple-system, BlinkMacSystemFont, Segoe UI, Roboto, sans-serif）
- **标题**：渐变色（`#60a5fa` → `#a78bfa`，蓝紫渐变），居中显示
- **卡片**：圆角 12px，深色背景 `#1e293b`，边框 `#334155`
- **按钮**：圆角 6px，蓝色主按钮 `#3b82f6`，绿色成功 `#059669`，红色危险 `#dc2626`

### 1.2 导航结构

页面顶部有 **6 个 Tab 标签**，点击切换不同功能区域：

| Tab | 名称 | 功能描述 |
|-----|------|----------|
| 1 | **概览** | 仪表盘总览，关键指标 + 图表 + 健康状态 |

#### 2.2.3 服务商编辑 Modal

点击"添加服务商"或"编辑"按钮时弹出，包含以下表单区域：

**基本信息**：
- ID（唯一标识，如 openai、internal-llm）
- 名称（显示名称）
- Base URL（API 基础地址）
- API 类型（下拉选择：openai）
- 认证方式（下拉选择：API Key / 动态Token）
- 权重（负载均衡权重，数字输入）
- 绕过代理（开关，用于内网服务商绕过系统代理）

**API Key 认证区域**（选择"API Key"时显示）：
- API Key 输入框

**动态 Token 认证区域**（选择"动态Token"时显示）：
- 获取 Token 的 URL
- 账号 / 密码
- 请求方式（POST / GET）
- 请求格式（JSON / Form）
- 账号字段名（如 username、account、email）
- 密码字段名（如 password、secret、pwd）
- 自定义请求体模板（可选，支持 `{{username}}` 和 `{{password}}` 占位符）
- 自定义请求头（可选，JSON 格式）
- Token 字段名（支持点号路径，如 token、result.token）
- Refresh Token 字段名
- 发送请求时的 Header 字段名（如 Authorization、X-Token）
- Header 值前缀（如 "Bearer "、""）
- Token 有效期（秒）

**响应内容路径区域**：
- 响应内容路径（默认 `choices.0.message.content`，支持点号和数组索引）
- 推理内容路径（默认 `choices.0.delta.reasoning_content`）

#### 2.2.4 模型管理

点击服务商行的"模型管理"按钮后，在服务商列表下方展开模型管理面板：

**操作栏**：
- 输入框：输入模型 ID（如 gpt-4o、deepseek-chat）
- **+ 添加模型**（绿色按钮）
- **🧪 全部测试连接**：一键测试该服务商下所有模型
- **📋 批量设置对外ID**：展开批量设置区域
- 搜索框：按模型名称搜索

**模型列表**：

| 列名 | 说明 |
|------|------|
| 服务商模型ID | 在服务商处的原始模型 ID |
| 对外ID | 对外暴露的统一模型 ID（全局唯一） |
| 状态 | 活跃/停用 |
| 测试结果 | 成功/失败信息（移动端隐藏） |
| 测试时间 | 最近一次测试时间（移动端隐藏） |
| 操作 | 测试连接 / 设置对外ID / 删除 |

**当前模型**：

| 服务商 | 模型ID | 对外ID | 测试状态 |
|--------|--------|--------|----------|
| MiniMax-CodingPlan | MiniMax-M2.7-highspeed | （需配置） | ✅ 成功 |
| astroncodingplan | astron-code-latest | （需配置） | ✅ 成功 |

**对外ID 机制**：
- 服务商模型必须配置"对外ID"才能被外部请求使用
- 对外ID 全局唯一，外部请求使用对外ID而非服务商模型ID
- 支持多个服务商映射到同一对外ID，实现负载均衡
- 批量设置：输入前缀 + 自动拼接模型ID（如 `prefix-model_id`）

## 三、UI 交互特性

### 3.1 响应式设计

- 使用 `hide-mobile` CSS 类在移动端隐藏次要列
- 统计卡片使用 `auto-fit` 网格布局，自动适配屏幕宽度
- Tab 导航支持 `flex-wrap`，窄屏时自动换行

### 3.2 实时刷新

- **Token 速率曲线**：概览页自动定时刷新（离开页面时停止）
- **API Key 用量图**：概览页自动定时刷新（离开页面时停止）
- **服务商健康状态**：显示数据更新时间戳

### 3.3 Modal 弹窗

所有编辑/创建/详情操作均使用 Modal 弹窗，不跳转页面：
- 服务商编辑 Modal（含动态 Token 区域的条件显示）
- API Key 创建/编辑 Modal
- API Key 显示 Modal（创建后仅显示一次）
- 日志详情 Modal（QA/原始模式切换）
- 配额校准 Modal

### 3.4 数据导出

- 请求日志支持 **CSV 导出**

### 3.5 批量操作

- 服务商支持全选/批量启用/批量停用
- 日志支持按服务商/按 API Key 批量清理

### 3.6 安全特性

- API Key 创建后仅显示一次完整值
- API Key 列表中只显示前缀（`lgk-xxxxxxxx`）
- 重新生成 API Key 需二次确认
- 删除操作均需确认对话框
- 日志详情中敏感信息适当脱敏
